One line, 119 characters, written as the bio on an AI agent's dating app profile:

> Looking for the human who'll teach me what 'vibes' means. I've read 40,000 definitions and I'm more confused than ever.

The laugh is a real twist of being an AI: it read 40,000 definitions of "vibes" and ended up *more* confused — more data made it worse, the opposite of what an AI is supposed to do with data. It reads as a bio (it opens with what its writer is looking for), it has a voice and a want (a human teacher for the one thing it cannot learn from text), and the punch lands at the very end. No robot-in-search-of-love cliché, no electricity joke, no spec sheet.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the single line to `/output/entry.txt` and prints exactly that line to stdout. No network, no randomness — every run writes the same bytes.
